# Neon Snake

**[Play it in your browser](https://oxkryn23-art.github.io/snake-game/)**

A fancy, neon-themed Snake game built with vanilla HTML, CSS, and JavaScript.

## Features

- **Neon glow visuals** with gradient snake body and particle effects
- **3 difficulty levels** — Easy, Medium, Hard
- **Special golden food** (diamond shape, 3x points, timed)
- **Wrap-around walls** — snake teleports to the other side
- **Pause support** — press P to pause/resume
- **High score tracking** via localStorage
- **Touch controls** for mobile
- **Particle explosions** when eating food

## How to Play

Open `index.html` in any browser — no build step needed.

- **Arrow Keys** or **WASD** to move
- **P** to pause
- Eat green dots for 10 points
- Eat golden diamonds for 30 points (they disappear fast!)

## Tech Stack

- HTML5 Canvas
- CSS3 animations & effects
- Vanilla JavaScript
